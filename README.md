# 🚲 자전거 출근 가계부

자전거로 출근한 날을 한 번의 탭으로 기록하고, 절약한 교통비를 자동으로 모아주는 웹앱입니다.

- **메인** — 오늘 출근 방법(🚲/🚗)을 한 번 탭해서 기록
- **달력** — 달별로 출근 기록을 확인하고 지난 날짜도 채우기
- **통계** — 이번 달 절약액 · 현재 streak · 누적 절약액
- **내보내기** — 엑셀(.xlsx) / CSV 저장

하루 절약 기준: **6,000원** (자동차 기름값 + 톨비)

## 사용법

`index.html` 하나로 동작하는 단일 파일 웹앱입니다. 기록은 브라우저(localStorage)에 저장되어, 같은 기기·브라우저에서 다시 열면 그대로 유지됩니다.
